# VoxStudio local voice engine (server.py)
#
# Coqui XTTS-v2 for zero-shot voice cloning + TTS, served over HTTP.
# The `coqui-tts` package is the maintained community fork of the original
# (now-discontinued) Coqui `TTS` project and exposes the same `TTS` import.
#
# A GPU is optional but strongly recommended — CPU synthesis works but is slow.
# ffmpeg must be installed on the system for audio decoding (pydub).

# PyTorch and torchaudio are required but are NOT pulled in automatically by
# coqui-tts (they are left optional so you can choose a CPU or CUDA build).
# On Windows/Linux the default wheels include CUDA support; on macOS, CPU/MPS.

torchaudio>=2.1
